# LT Hormigones · Sistema de planta

App web para la operación diaria de la planta de hormigón de Logística Transportadora S.A.:
remitos (3 copias), pedidos, stock de cemento/áridos/agua, cobros, flota, choferes y movimiento de suelos.

- No necesita instalar nada: es HTML + JavaScript que corre en el navegador.
- Datos y usuarios: Supabase (`supabase/01_esquema.sql` y `supabase/02_datos_iniciales.sql`).
- Configuración: `config.js` (URL y clave pública de Supabase).
- Sin configurar, abre en **modo demostración** (usuario `admin` / `admin`).

La guía de instalación y el manual de uso están en los documentos que acompañan este proyecto.
